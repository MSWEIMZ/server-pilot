# Server Pilot 收敛与安全加固设计

## 目标

将 `C:\Users\WEI\server-pilot` 作为唯一的 Server Pilot 源码与运行配置来源，并消除已审计出的仪表盘暴露、弱 SSH 主机校验、无边界日志读取和运行时依赖安装问题。

## 范围与边界

- 选用原 Codex 安装目录中结构最完整的三服务器配置，迁入源码库的 `scripts/server_config.json`。
- 所有旧配置和目录先备份；备份目录不纳入 Git，且执行过程不输出凭据。
- 仅将真实安装目录改为指向源码库的 Windows 目录联接。插件缓存、Reasonix 缓存和当前 `Documents` 空工作区不改动。
- 不连接服务器、不执行远程命令、不修改远程文件。

## 目录与配置

源码库保留所有代码和唯一的 `scripts/server_config.json`。Codex、Claude、CC Switch、Qoder、CodeBuddy、ZCode 的 Skill 目录均改为目录联接，因此它们读取同一代码和配置。迁移前的目录与配置复制到用户本地、Git 忽略的时间戳备份目录，以便回退。

## 仪表盘安全模型

仪表盘默认仅监听 `127.0.0.1`，并且不发送宽松 CORS 响应头。远程绑定必须由显式参数开启，同时要求访问令牌；所有 API 请求需要 Bearer token。日志接口只接受正整数 PID，并将返回行数限制为合理区间；所有进入远程 shell 的路径使用 POSIX shell 安全引用。进程环境变量不再作为 API 响应返回。

## SSH 与依赖策略

所有 SSH 入口加载用户 known_hosts 与项目专用 known_hosts，并使用拒绝未知主机密钥的策略。未知密钥时，命令失败并给出明确的人工登记步骤；不再静默信任。缺少 `paramiko` 时脚本只给出安装提示，不再自动调用 pip 修改运行环境。

## 验收标准

1. 源码库包含三服务器配置，安装目录均解析为同一联接目标。
2. 仪表盘默认无法通过非回环地址访问；远程模式无令牌无法读取 API。
3. 非法 PID、过大日志行数和带引号的路径不进入不安全的远程命令拼接。
4. 未知 SSH 主机密钥被拒绝；缺失 paramiko 不触发 pip。
5. 全部 Python 文件通过语法编译，新增自动化测试覆盖安全行为。
